# 🎓 CLO & PLO Reporting Dashboard
### Diploma Pemasaran — Politeknik Sultan Azlan Shah (PSAS)

A Streamlit-based interactive dashboard for reporting **Course Learning Outcomes (CLO)** and **Program Learning Outcomes (PLO)** attainment.

---

## 📋 Features

| Page | Description |
|---|---|
| 🏠 **Home / Overview** | Program summary, 11 PLO status cards, overall attainment bar chart |
| 📊 **PLO Dashboard** | Radar chart, bar chart, domain analysis, detailed PLO table |
| 📚 **Course CLO** | CLO attainment per course, year trend, CLO→PLO mapping per course |
| 🗺️ **CLO-PLO Mapping** | Heatmap, full mapping matrix, PLO coverage analysis |
| 📈 **Trend Analysis** | Year-on-year PLO trend, semester comparison, change table |

---

## 🚀 Quick Start

### 1. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 2. Generate sample Excel template (first time only)

```bash
python generate_template.py
```

This creates `data/template_data.xlsx` with 40 sample courses and 3 years of data.

### 3. Run the dashboard

```bash
streamlit run app.py
```

Open your browser at: **http://localhost:8501**

---

## 📊 Data Input

### Option A: Use Sample Data
Select **"Use Sample Data"** in the sidebar — no file needed.

### Option B: Upload Your Own Data

Fill in `data/template_data.xlsx` (or use it as a template) with **2 sheets**:

#### Sheet: `CLO_Attainment`

| Column | Description |
|---|---|
| `Course` | Course/subject name |
| `CLO` | CLO code (e.g., CLO1, CLO2) |
| `Attainment` | CLO attainment in % (0–100) |
| `Semester` | Semester 1 or Semester 2 |
| `Year` | Academic year (e.g., 2024) |

#### Sheet: `CLO_PLO_Mapping`

| Column | Description |
|---|---|
| `Course` | Must match `CLO_Attainment` |
| `CLO` | Must match `CLO_Attainment` |
| `PLO1`–`PLO11` | Put **1** if CLO contributes to PLO, **0** otherwise |

| PLO2 | Cognitive | Analyze issues and problems to provide solutions |
| PLO3 | Psychomotor | Perform marketing practical work skills |
| PLO4 | Interpersonal | Develop good relationships and interactions |
| PLO5 | Communication | Practice effective communication skills |
| PLO6 | Digital | Practice relevant digital skills in marketing |
| PLO7 | Numeracy | Analyze numerical and graphical data |
| PLO8 | Leadership | Adopt leadership skills to manage diverse team |
| PLO9 | Personal | Develop personal skills for self-improvement |
| PLO10 | Entrepreneurship | Demonstrate entrepreneurial skills |
| PLO11 | Professionalism | Display professionalism, positive attitudes and values |

**Target minimum attainment: 55%**

## 🌐 Deploy to Streamlit Cloud (Free)

1. Push this folder to a **GitHub repository**
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your GitHub repo
4. Set **Main file path** to `app.py`
5. Click **Deploy** — your dashboard is online!
